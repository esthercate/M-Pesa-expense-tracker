
# M-Pesa PDF Statement to Excel Converter

A simple web app to convert your M-Pesa PDF statements into Excel and analyze your spending, all in the browser.


### Homepage

![Homepage](/mpesa-expense-tracker/public/screenshot.png)


## Live Demo

- [Live Link](https://m-pesa-pdf-statement-to-excel-converter.vercel.app/)


## Features

- Upload M-Pesa PDF statements

- Convert to Excel instantly

- Fully client-side, no login or database required


## Technologies Used

- **Next.js** – React Framework
- **Zustand** – State management**
- **TypeScript** - Business logic
- **Tailwind CSS** – Styling
- **EmailJS** – Waitlist form handling
- **Vercel** – Deployment


## Installation

1. **Clone the repository**
   ```bash
   git clone https://github.com/esthercate/M-Pesa-expense-tracker.git
   cd mpesa-expense-tracker
  
2. Install dependencies
   ```bash
   pnpm install

3. Run the development server
   ```bash
   pnpm dev

4. Visit
   ```arduino
   http://localhost:3000
